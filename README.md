## 🚀 Getting Started

Follow these steps to run the project locally if it uses Node.js and npm.

### Prerequisites

- Node.js
- npm
- Git

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/kuvaleshcd-hue/vivek-shivaswamy-portfolio.git
   ```

2. Navigate to the project directory:

   ```bash
   cd vivek-shivaswamy-portfolio
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.

**Note:** These commands assume the repository uses a Node.js-based development setup. Check `package.json` for the correct scripts.
